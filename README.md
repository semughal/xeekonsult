# XEE KONSULT AB

Website for XEE KONSULT AB, featuring Swedish and English content for accounting, IT consulting, Microsoft cloud services, and web and mobile development.

## Run with Node.js

Requires Node.js 18 or newer. No third-party packages are needed.

```bash
npm start
```

Then open [http://localhost:3000](http://localhost:3000). Set the `PORT` environment variable to use a different port.

## Preview without Node.js

You can also open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
